# Roadmap

## Phase 0: cleanup/security

Quarantine old projects, revoke all exposed credentials, add secret scanning, extract safe code only.

## Phase 1: core substrate

Bring up Postgres/PostGIS/pgvector, NATS, MinIO, API gateway, module registry, health checks.

## Phase 2: sync engine

Implement device identity, vector clocks, conflict resolution, attachment sync, sync dashboard.

## Phase 3: first three modules

Study, Zettelkasten, Geospatial.

## Phase 4: mobile/desktop packaging

Quasar/Capacitor Android and Tauri desktop shells with private-mesh URLs.

## Phase 5: geospatial/AR/research expansion

TileServer, pgRouting, AR anchors, research ingestion, SearXNG, document cache, embeddings.

## Phase 6: automation and agentic workflows

n8n bridge, internal DAG workers, command bus approval flows, local coding harness adapters.
